A fast triage pass. Use when the user wants a read on a site, not a full program.

1. Read `input/site-profile.md`. If `$1` is given, use it as the domain and do
   not block on missing profile fields — infer what you can from the live site.
2. Launch `seo-recon` and wait.
3. Launch `technical-seo-engineer` and `aeo-strategist` in parallel.
4. Report inline in chat (no executive summary file): the 10 biggest problems
   found, ranked by impact, each with the evidence and the fix.
5. End with one line: what a full `/seo-360` would add that this pass skipped.

Do not fabricate anything to fill gaps. "Could not determine without GSC access"
is a valid and useful finding.
