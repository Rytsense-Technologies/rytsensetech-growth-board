COMPUTATION RULES:
1) GSC current = last 28 full days ending yesterday (UTC). Prior = the 28 days before that.
2) ctr is a percentage (e.g. 1.11), not a fraction. Round ctr to 2 decimals, position to 1 decimal.
3) change.clicks = current - prior; clicksPercent = ((current-prior)/prior)*100 if prior>0 else 0. Same for impressions. change.ctr / change.position = simple differences.
4) quickWins: position 4–15 AND impressions >= 100. opportunity = round(impressions * (1 - ctr/100) * 0.05 * (16 - position)). Sort opportunity desc; top 8.
5) GA4 = last 28 days through today. engagementRate = sessions-weighted average, 4 decimals. daily[].date = YYYYMMDD. channels = sessionDefaultChannelGroup, sessions desc.
6) github.recentCommits: up to 5; message = first line only.
7) If analytics env/files missing or API blocked: cloudflare.status may still be "ok" after a successful Pages deploy with analytics zeros OR status "unavailable" with note — prefer: after successful npm run deploy:cf set cloudflare.status="ok", deployment.status="success", deployment.url from wrangler output, deployment.deployedAt=now, and leave analytics at 0 with a note only if you must explain missing analytics (put that in cloudflare.note). If deploy also fails, set deployment.status="failed" and note the error.
8) Write data/latest.json as **compact/minified JSON** (JSON.stringify with no extra spaces) + trailing newline.
   Reason: pretty ~325KB often fails Claude→GitHub Contents relay; minified full rows usually succeed.
   Do NOT drop rows to shrink. updatedAt = now UTC.
